## 🌟 Overview

Welcome to my personal portfolio repository! I'm **Ala**, a first-year IT student passionate about the intersections of **Artificial Intelligence**, **Computer Engineering**, and **interactive 3D graphics**.

This website was built from scratch without bulky frameworks to deliver a lightweight, high-performance (60 FPS) visual experience inspired by cutting-edge commercial creative design.

---

## ✨ Key Features

- **⚛️ Real-time 3D Quantum Neural Core:** Built with **Three.js**; features a pulsating central nucleus, rotating electron orbital rings, and dynamic laser synapses.
- **🧠 4 Scientific Visualization Modes:**
  - `🧠 Neural Brain` — Dense synaptic network firing live thought pathways.
  - `⚛️ Quantum Atom` — High-speed electron orbits & wave interference.
  - `⚡ Synaptic Surge` — Maximum frequency algorithmic energy discharge.
  - `🌌 Deep Space` — Serene low-entropy cosmic equilibrium.
- **🖱️ Physics-Driven 3D Interactions:**
  - Real-time 3D tilt tracking cursor position.
  - 360° click-and-drag rotation of the quantum core.
  - Sleek custom quantum cursor with trailing halo physics.
- **📁 Modular Architecture:** All projects, skills, and social links are managed centrally in `data.js` for zero-friction updates.
- **👁️ Eye-Friendly Aesthetic:** Deep obsidian/charcoal canvas (`#070810`) with gentle cyan and lavender accents designed for comfortable, strain-free viewing.

## 🚀 Local Development

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/benabdelhafidhala/My_First_Project.git
   cd My_First_Project
   ```

2. **Open the project:**
   - Simply open `index.html` in any modern web browser.
   - Or use VS Code's **Live Server** extension for real-time live reloading.

---

## ⚙️ Customization

Want to add a new project or update social profiles? You don't need to touch `index.html`! Simply edit [`data.js`](data.js):

```javascript
// Example: Add a new project in data.js
projects: [
  {
    title: "My New AI Project",
    category: "Machine Learning",
    description: "Brief description of the project.",
    tags: ["Python", "PyTorch"],
    github: "https://github.com/...",
    demo: "https://..."
  }
]
```
