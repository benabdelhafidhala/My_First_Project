## 🌟 Overview

Welcome to my personal developer CV repository! I'm **Ala**, a first-year IT & Computer Engineering student passionate about **Artificial Intelligence**, **software architecture**, and **interactive digital experiences**.

This CV website is designed to be **clean, readable, and dynamic**:
- ❌ **No heavy, rigid boxes** or visual clutter.
- ✅ **Flowing, editorial typography** that's effortless to scan.
- ✅ **Ambient 3D mathematical particle wave** running at 60 FPS in Three.js.
- ✅ **Centralized data configuration** via [`data.js`](data.js).

---

## 📂 CV Sections

1. **01 / Education & Background:** Academic degree, coursework, and core engineering foundations.
2. **02 / Technical Skills & Stack:** Categorized competencies (AI & Data Science, Web & Interactive, Systems & Tools).
3. **03 / Selected Projects:** Interactive project rows with year, tags, summaries, and direct repository links.
4. **04 / Passions & Mindset:** Exploration in AI, audio synthesis, and nature.
5. **05 / Connect:** Direct channels to collaborate or get in touch.

## ⚙️ Updating Your CV

All content is managed centrally in [`data.js`](data.js). To update your details, just edit the fields in `data.js`:

```javascript
// Example: Add a new skill in data.js
skills: {
  "AI & Data Science": ["Machine Learning", "Neural Networks", "PyTorch", "Python"],
  // ...
}
```
